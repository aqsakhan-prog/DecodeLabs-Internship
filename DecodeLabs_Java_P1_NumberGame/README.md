# Project 1: Number Guessing Game

## Description
A simple Java console game where the player tries to guess a randomly generated number between 1 and 100.

## Features
- Generates a random number.
- Tells the player whether the guess is too high or too low.
- Accepts user input.
- Handles invalid input.

## Concepts Used
- Java variables and data types
- Random numbers
- Loops and conditional statements
- User input and input validation

## How to Run
Run these commands in the project folder:

```bash
javac DecodeLabs_Java_P1.java
java DecodeLabs_Java_P1
```
