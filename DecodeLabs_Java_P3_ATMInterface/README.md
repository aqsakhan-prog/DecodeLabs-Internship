# Project 3: ATM Interface

## Description
A Java console-based ATM simulation that allows users to manage a demo bank account through a menu.

## Features
- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Validate user input
- Prevent withdrawals exceeding the available balance

## Concepts Used
- Object-oriented programming
- Classes and objects
- Encapsulation
- Methods
- ArrayLists and transaction history
- Input validation

## Files
- `ATM.java`: Handles the ATM menu and user interaction.
- `BankAccount.java`: Manages the account balance and transaction history.

## How to Run

```bash
javac ATM.java BankAccount.java
java ATM
```

**Note:** This is an educational simulation with a demo balance, not a real banking application.
