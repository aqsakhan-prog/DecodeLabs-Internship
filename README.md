# DecodeLabs Java Programming Internship

Welcome to my Java Programming Internship project repository for DecodeLabs.

This repository contains Java projects developed to practise programming fundamentals, input validation, problem-solving, and object-oriented programming.

## Projects

### Project 1: Number Guessing Game
A console-based game in which the player guesses a randomly generated number between 1 and 100.

**Concepts:** Random numbers, loops, conditionals, and input validation.

**Run:**
```bash
javac DecodeLabs_Java_P1.java
java DecodeLabs_Java_P1
```

### Project 2: Student Grade Calculator
A console-based application that accepts marks for multiple subjects and calculates the total, average percentage, and grade.

**Concepts:** Variables, loops, arithmetic, conditionals, and input validation.

**Run:**
```bash
javac DecodeLabs_Java_P2.java
java DecodeLabs_Java_P2
```

**Note:** The grading scale used in this project is an assumed scale because the project instructions did not specify official grade boundaries.

### Project 3: ATM Interface
A console-based ATM simulation that supports balance checking, deposits, withdrawals, and transaction history.

**Concepts:** Classes, objects, encapsulation, methods, and input validation.

**Run:**
```bash
javac ATM.java BankAccount.java
java ATM
```
