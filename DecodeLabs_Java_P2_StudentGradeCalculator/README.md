# Project 2: Student Grade Calculator

## Description
A Java console application that calculates students' total marks, average percentage, and grade based on the marks entered for multiple subjects.

## Features
- Accepts marks for multiple subjects.
- Calculates total marks and average percentage.
- Assigns a grade based on the implemented grading scale.
- Validates marks entered by the user.

## Concepts Used
- Variables and arithmetic operations
- Loops and conditional statements
- User input and input validation

## Grading Scale
- 90–100: A+
- 80–89: A
- 70–79: B
- 60–69: C
- 50–59: D
- Below 50: F

*Note: This grading scale is an assumed scale because the project instructions did not specify official grade boundaries.*

```bash
javac DecodeLabs_Java_P2.java
```
